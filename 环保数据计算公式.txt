============================================
FoodGuardian AI — 环保数据计算公式
============================================

用户生成食谱后，系统根据以下流程自动计算 3 项环保贡献。


一、输入数据（由用户食谱提供）

  食材列表    例如：鸡肉、西兰花、胡萝卜
  就餐人数    例如：2 人
  用餐类型    家常 / 健康 / 素食 / 宴客
  饭量系数    0.5 ~ 2.0（默认 1.0）


二、前置计算 — 总份量

  ┌─────────────────────────────────────────────────────┐
  │ total = Σ( 食材基础份量 × 人数 × 餐型系数 × 饭量 )  │
  │                                                     │
  │  基础份量：查食材数据库（如鸡肉 150g/人）              │
  │  餐型系数：家常=1.0  健康=0.9  素食=0.85  宴客=1.15  │
  └─────────────────────────────────────────────────────┘


三、三条核心公式

  ┌──────────────────────────────────────────────────────────────┐
  │                                                              │
  │   公式一：减少食物浪费 (food_waste)                            │
  │                                                              │
  │   food_waste = total × 0.25                                  │
  │                           ↑                                  │
  │                    传统做法浪费率 25%                           │
  │                    来源：FAO 联合国粮农组织                       │
  │                                                              │
  │   含义：用智能份量计算，避免了传统多买多做造成的食物浪费              │
  │                                                              │
  ├──────────────────────────────────────────────────────────────┤
  │                                                              │
  │   公式二：节约水资源 (water)                                    │
  │                                                              │
  │   water = food_waste × 0.5                                   │
  │                        ↑                                     │
  │                 水足迹系数 0.5 L/g                             │
  │                 来源：Water Footprint Network                  │
  │                                                              │
  │   含义：每克食物背后隐藏的水足迹 ≈ 0.5 L/g                        │
  │        （种植灌溉 + 加工 + 运输全链条耗水）                       │
  │                                                              │
  ├──────────────────────────────────────────────────────────────┤
  │                                                              │
  │   公式三：减少碳排放 (carbon)                                   │
  │                                                              │
  │   carbon = food_waste × 3.0                                  │
  │                        ↑                                     │
  │                 碳足迹系数 3.0 g CO₂e/g                        │
  │                 来源：食物全生命周期碳足迹研究                       │
  │                                                              │
  │   含义：每克食物背后隐含的碳排放 ≈ 3.0 g CO₂e/g                  │
  │        （生产 + 运输 + 储存 + 废弃处理全链条排放）                 │
  │                                                              │
  └──────────────────────────────────────────────────────────────┘


四、公式关系图

        用户食材数据
             │
             ▼
     ┌───────────────┐
     │  total = Σ份量  │
     └───────┬───────┘
             │ × 0.25
             ▼
     ┌───────────────┐
     │   公式一       │ → 减少食物浪费 food_waste (g)
     │ food_waste     │
     └───────┬───────┘
             │
      ┌──────┴──────┐
      │ × 0.5       │ × 3.0
      ▼             ▼
  ┌───────┐     ┌───────┐
  │公式二  │     │公式三  │
  │ water │     │carbon │
  └───────┘     └───────┘
  节约水资源    减少碳排放
  (L)          (g CO₂)


五、举例：2 人份「鸡肉 + 西兰花 + 胡萝卜」家常餐

  基础份量：鸡肉 150g + 西兰花 200g + 胡萝卜 150g = 500g/人
  total    = 500 × 2 人 × 1.0(家常) × 1.0(饭量) = 1000g

  公式一  food_waste = 1000 × 0.25  = 250.00 g    ← 减少食物浪费
  公式二  water      =  250 × 0.5   = 125.00 L    ← 节约水资源
  公式三  carbon     =  250 × 3.0   =   750 g     ← 减少碳排放 (CO₂e)


六、代码位置

  food_guardian_ai_2.py  calculate_impact()  计算函数
  同文件                  MEAL_MULTIPLIERS (餐型系数)
  同文件                  ENV_FACTORS (water_per_g / co2_per_g)
  同文件                  WASTE_RATIO = 0.25


* 本模型为教育科普用途的简化估算。实际数据受食材产地、
  运输距离、季节等因素影响。参考 FAO、Water Footprint Network。
